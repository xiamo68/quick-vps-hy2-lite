# HY2 Lite 公开版首发计划

首版支持从全新的 Ubuntu 24.04 VPS 搭建个人 Hysteria2 和 HY2 Lite 面板。开发使用独立环境，已有 VPS 的迁移不在首版范围内。

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 1. 检测与包结构 | `check.sh`、`deploy/preflight.py`、`config/install.example.env` 和发布文件清单 | 自动检测公网 IPv4，校验部署包文件，报告本机失败项和待验证项 |
| 2. 自动安装 | `install.sh`、依赖清单、应用代码、配置模板和服务文件 | 用公网 IP 登录 HTTPS 面板，证书可自动续期，安装失败后可重试 |
| 3. 安装验收 | `verify.sh` 和验收指南 | 验证 TLS、真实代理认证、流量入库与外部访问 |
| 4. 域名与运维 | 域名绑定入口、备份恢复与运维指南 | 绑定后原 IP 入口及订阅继续可用，验证续期、重启和恢复 |
| 5. GitHub 发布 | 公开源码、README 下载区、许可证、版本包和校验值 | 从同一个发布标签生成部署包，在另一台干净 VPS 上按公开指南复验 |

## 新手路径

1. 在服务商控制台创建干净 VPS，获取公网地址，设置 SSH 密钥并登录。保留当前 SSH 会话，直到防火墙配置检查通过。
2. 按指南配置云防火墙与主机防火墙，分别检查 Web 的 TCP 端口与代理的 UDP 端口。域名选填，可在安装后绑定。
3. 下载指定版本的部署包并解压。检测脚本校验包内文件，自动获取公网 IPv4，报告系统、路径、DNS 或端口冲突。
4. 确认安装将写入的路径，部署服务与证书，在终端交互设置管理员密码。通过 HTTPS 登录面板。
5. 在网页创建第一个用户，导入订阅，通过真实客户端访问测试站点。验证用量入库、禁用后拒绝新连接、启用后恢复。使用临时账号验证删除。
6. 重启 VPS 后检查服务并再次连接。从备份恢复到另一套隔离环境，核对管理员、订阅与流量历史。

## 命令范围

| 命令 | 首版行为 |
| --- | --- |
| `check.sh` | 已实现本机检查。检查系统、工具、磁盘、Ubuntu 官方源可达性、监听端口与安装路径。已填域名时校验本机 IPv4 解析。 |
| `install.sh` | 已实现 IP 安装、可选域名绑定、备份和同 IP 恢复，待干净 VPS 实测。 |
| `verify.sh` | 已实现本机与外部验收入口，待干净 VPS 联合实测。检查服务、证书、代理认证和按用户流量。见[验收指南](VERIFY.md)。 |

首版使用公网 IPv4 和单实例，目标架构为 amd64。代理默认使用 UDP 24443，可在配置中修改。服务内部端口监听回环地址，公网 HTTPS 由 Web 入口提供。证书自动续期和重载流程已实现，真实续期仍需要验收。见[全新 VPS 安装](FRESH_INSTALL.md)。

在测试 VPS 上进入解压后的目录运行：

```bash
bash check.sh
```

返回 0 表示没有发现阻止安装的本机问题，1 表示检查失败，2 表示参数或配置有误。可用 `--config PATH` 指定配置文件。安装需要 root 权限。普通用户运行检查时，能否提权若未确认会标为待验证。云防火墙需放行 Web 的 TCP 80/443 和代理 UDP 端口。公网 IP 归属、外部连通性和证书签发要在后续验收中验证。

## 发布条件

- GitHub 公开仓库可直接查看脚本、面板源码、模板、文档和测试。README 提供单个 GitHub Release 部署包下载链接，包内含 `SHA256SUMS`。
- 部署包按 [发布文件清单](../deploy/release-files.txt) 生成，候选包与公开源码构建方式见[发布指南](RELEASE.md)。公开源码和部署包均排除现有 VPS 的迁移脚本、旧归档、生产域名、账号映射、实际配置、数据库、密钥和订阅。
- 公共指南与快速安装共用入口。从干净 VPS 验收 HTTPS、真实代理认证、流量统计、账号操作、续期方案、开机自启和恢复。
- 公开前确定项目许可证，经用户授权后创建公开仓库并发布版本。验收日志只记录状态，隐藏凭据和订阅地址。
