# 构建和发布

在项目根目录运行：

```bash
python3 deploy/build_release.py 0.1.0-rc dist/0.1.0-rc
```

构建输出单个部署包和 `public-source/`。包内的 `SHA256SUMS` 供 `check.sh` 在解压后自动校验项目文件。构建命令另在终端打印压缩包本身的摘要，可放入 GitHub Release 供需要在解压前校验的人使用。公开 GitHub 仓库放 `public-source/` 中的文件，README 提供该 Release 的下载链接。

1. 先在全新 Ubuntu 24.04 amd64 VPS 中只使用候选包和公开指南，完成 IP 安装及外部认证。
2. 验证按用户流量、绑定域名后旧订阅继续可用、自动续期、重启和备份恢复。
3. 复核公开源码和包内文件，确定许可证并核对项目的第三方依赖声明。在公开 README 中放入维护者提供的实拍截图，并确认截图不含真实账号、订阅 URL 或凭据。发布文件清单使用截图的明确文件名，避免打包其他图片。
4. 用同一份公开源码打标签并构建正式部署包。经维护者授权后发布，并填入 Release 下载链接。

候选包只供安装验收。当前实际续期、重启、恢复和公网验证尚待测试。
